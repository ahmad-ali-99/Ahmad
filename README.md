# قاعدة بيانات عشيرة السوره ميري 📋

نظام اونلاين لجمع بيانات أبناء العشيرة (ذكور فقط) — الاسم الكامل، رقم الهاتف، العنوان، والموقع الجغرافي (GPS).

**كيف يشتغل النظام؟**

- الاستمارة: صفحة ويب (`index.html`) ترفعها مجاناً على GitHub Pages، أي شخص يفتح الرابط ويسجل بياناته من الموبايل.
- قاعدة البيانات: جدول **Google Sheets** بحسابك على جوجل — كل تسجيل جديد ينضاف سطر تلقائياً، ويشمل رابط مباشر لموقع الشخص على خرائط جوجل.

---

## خطوات التنصيب (مرة وحدة فقط)

### الخطوة 1: إنشاء جدول Google Sheets

1. افتح [sheets.google.com](https://sheets.google.com) من حسابك بجوجل.
2. أنشئ جدول جديد (Blank) وسمّيه مثلاً: **قاعدة بيانات عشيرة السوره ميري**.

### الخطوة 2: إضافة كود Apps Script

1. من داخل الجدول، افتح القائمة: **Extensions ← Apps Script** (الإضافات ← برمجة التطبيقات).
2. احذف أي كود موجود، وانسخ كل محتوى ملف [`google-apps-script.gs`](google-apps-script.gs) والصقه هناك.
3. اضغط على أيقونة الحفظ 💾.

### الخطوة 3: نشر التطبيق

1. اضغط زر **Deploy ← New deployment** (نشر ← نشر جديد).
2. اضغط أيقونة الترس ⚙️ واختر **Web app** (تطبيق ويب).
3. عبّي الإعدادات:
   - **Execute as**: أنا (Me / حسابك)
   - **Who has access**: **Anyone** (أي شخص) ← مهم جداً حتى تشتغل الاستمارة للجميع.
4. اضغط **Deploy** ووافق على الصلاحيات (اضغط Advanced ← Go to project إذا طلع تحذير).
5. انسخ الرابط الذي يبدأ بـ `https://script.google.com/macros/s/...../exec`

### الخطوة 4: ربط الاستمارة بقاعدة البيانات

1. افتح ملف `index.html` وعدّل هذا السطر (موجود بأول الـ script):

```js
const SCRIPT_URL = "PASTE_YOUR_GOOGLE_SCRIPT_URL_HERE";
```

2. بدّل `PASTE_YOUR_GOOGLE_SCRIPT_URL_HERE` بالرابط الذي نسخته بالخطوة 3.

### الخطوة 5: تشغيل الاستمارة اونلاين (GitHub Pages)

1. من صفحة المستودع على GitHub، روح إلى: **Settings ← Pages**.
2. عند **Branch** اختر الفرع الرئيسي (main) ثم مجلد **/ (root)** واضغط **Save**.
3. بعد دقيقة أو دقيقتين يصير عندك رابط مثل:
   `https://ahmad-ali-99.github.io/ahmad/`
4. انشر هذا الرابط بگروب العشيرة (واتساب / تيليگرام) وكل شخص يسجل بياناته بنفسه.

## شنو يوصلك بالجدول؟

| العمود | الوصف |
|--------|-------|
| التاريخ والوقت | وقت التسجيل تلقائياً |
| الاسم الكامل | الاسم الرباعي واللقب |
| رقم الهاتف | رقم الموبايل |
| العنوان | المحافظة والمنطقة |
| خط العرض / خط الطول | إحداثيات GPS (إذا سمح الشخص بالموقع) |
| رابط الموقع على الخريطة | رابط يفتح موقع الشخص مباشرة على خرائط جوجل |

## ملاحظات مهمة

- تحديد الموقع (GPS) **اختياري** — إذا الشخص ما سمح للمتصفح، تنحفظ باقي البيانات بدون الموقع.
- الموقع يشتغل فقط عبر رابط `https` (رابط GitHub Pages آمن ويدعمه).
- البيانات محفوظة بحسابك أنت فقط على جوجل — ولا أحد غيرك يشوف الجدول إلا إذا شاركته بنفسك.
- إذا عدّلت كود Apps Script لاحقاً، لازم تسوي **Deploy ← Manage deployments ← Edit ← New version** حتى يشتغل التعديل.
