# قاعدة بيانات عشيرة السوره ميري 📋

نظام اونلاين لجمع بيانات أبناء العشيرة (ذكور فقط) — الاسم الكامل، رقم الهاتف، العنوان، والموقع الجغرافي (GPS).

كل تسجيل ينحفظ تلقائياً سطر جديد في جدول **Google Sheets** بحسابك، مع رابط مباشر يفتح موقع الشخص على خرائط جوجل.

---

## ✅ الطريقة الأولى (الأسهل — كلشي داخل جوجل، مستحسنة)

ملف واحد فقط يسوي الاستمارة وقاعدة البيانات سوية: [`apps-script-all-in-one.gs`](apps-script-all-in-one.gs)

1. افتح [sheets.google.com](https://sheets.google.com) وأنشئ جدول جديد وسمّيه: **قاعدة بيانات عشيرة السوره ميري**.
2. من داخل الجدول: **Extensions ← Apps Script** (الإضافات ← برمجة التطبيقات)، احذف الكود الموجود، والصق كل محتوى ملف `apps-script-all-in-one.gs`، ثم اضغط حفظ 💾.
3. اضغط **Deploy ← New deployment**، اختر ⚙️ **Web app**، وعبّي:
   - **Execute as**: Me (حسابك)
   - **Who has access**: **Anyone** ← مهم جداً
   
   ثم اضغط **Deploy** ووافق على الصلاحيات (إذا طلع تحذير اضغط Advanced ← Go to project).

**خلصت!** الرابط الذي يطلع لك (ينتهي بـ `/exec`) هو رابط الاستمارة — دزّه بگروب العشيرة (واتساب / تيليگرام)، وكل شخص يفتحه من موبايله ويسجل بياناته، وتوصلك فوراً بالجدول.

> ملاحظة: إذا عدّلت الكود لاحقاً، سوي **Deploy ← Manage deployments ← ✏️ Edit ← Version: New version ← Deploy** حتى يظهر التعديل.

---

## 🌐 الطريقة الثانية (استمارة على GitHub Pages)

الملفات: [`index.html`](index.html) (الاستمارة) + [`google-apps-script.gs`](google-apps-script.gs) (استقبال البيانات)

⚠️ **تنبيه:** هذه الطريقة تحتاج المستودع يكون **عام (Public)** لأن GitHub Pages بالحساب المجاني لا يشتغل على المستودعات الخاصة. لتحويله: **Settings ← General ← Danger Zone ← Change visibility ← Public**.

1. سوي الخطوات 1-3 من الطريقة الأولى لكن بملف `google-apps-script.gs` بدلاً منه، وانسخ رابط الـ `/exec`.
2. عدّل ملف `index.html`: بدّل `PASTE_YOUR_GOOGLE_SCRIPT_URL_HERE` برابطك.
3. حوّل المستودع إلى Public، وبعدها روح لتبويب **Actions ← نشر الموقع على GitHub Pages ← Run workflow** — ينشر الموقع تلقائياً ويصير رابطك:
   `https://ahmad-ali-99.github.io/Ahmad/`

## 📊 شنو يوصلك بالجدول؟

| العمود | الوصف |
|--------|-------|
| التاريخ والوقت | وقت التسجيل تلقائياً |
| الاسم الكامل | الاسم الرباعي واللقب |
| رقم الهاتف | رقم الموبايل |
| العنوان | المحافظة والمنطقة |
| خط العرض / خط الطول | إحداثيات GPS (إذا سمح الشخص بالموقع) |
| رابط الموقع على الخريطة | رابط يفتح موقع الشخص مباشرة على خرائط جوجل |

## ملاحظات مهمة

- تحديد الموقع (GPS) **اختياري** — إذا الشخص ما سمح للمتصفح، تنحفظ باقي البيانات بدون الموقع.
- البيانات محفوظة بحسابك أنت فقط على جوجل — ولا أحد غيرك يشوف الجدول إلا إذا شاركته بنفسك.
- بعض المتصفحات قد تمنع تحديد الموقع داخل صفحة Apps Script؛ إذا صار هيج، الطريقة الثانية (GitHub Pages) تدعم الموقع بشكل أفضل.
